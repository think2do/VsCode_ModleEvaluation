界面重设计 · 5 个方案

功能一个都没改，只重新组织布局与视觉。下面每个方案都是可点击打开的真实网页， 用同一份示例数据（赛博朋克那一轮对话）演示，方便直接对比观感。

所有方案共用一套设计令牌与基础组件（demos/shared.css）， 所以选中之后无论挑哪个，改动量都不大。双击各页面里的标题栏 / 品牌名可切换深浅色。

方案列表（点卡片打开）
1 三栏工作台 信息分区
把「对话 / 历史 / 控制项」拆成三栏，主区只留正文。原来顶部那两条勾选栏全部搬进右侧检视栏。
顶部只剩标题 + 全局按钮，纵向空间全给正文
「是否提问」与「是否显示」拆成两个开关，语义不再打架
卡片用 auto-fill 自动换行，比强制横向滚动更好读
新增「本轮统计」：最快 / 最慢 / 成败数 / 字数
适合：日常主力使用 打开 →
2 对齐对比网格 强对齐
把并排对比当表格做：列头吸顶、列等宽、每轮一行。滚动时永远知道哪一列是哪个模型。
列头吸顶 + 轮次号固定，长会话里不会「忘记在看谁」
列头直接带状态点、平均耗时、复制按钮
「显示结果」变成收起整列，对齐结构不被打乱
列宽可拖拽，双击手柄恢复默认
适合：横向逐条比对答案 打开 →
3 聚焦阅读 + 侧栏对比 长文友好
模型变多后并排卡片会挤成窄条。这里改成「一次读一篇」，右侧细栏放其它模型的迷你预览，点一下即切换。
正文限宽 780px，长回答真正可读
选项卡直接标状态与耗时，失败 / 生成中一眼可见
顶部提供「单栏 / 双栏 / 平铺对比」三种视图切换
保留上一轮 / 下一轮导航，长会话翻阅更快
适合：回答长、模型多 打开 →
4 磁贴工作台 空间感
卡片变成有厚度感的磁贴（Bento），顶栏与输入区做成浮动小岛，历史收成抽屉。视觉最新，也最自由。
磁贴宽度可拖、双击复位，并实时显示当前像素宽度
可指定「主模型」磁贴，给更宽的版位
输入区悬浮，长会话滚动时不会被顶走
历史抽屉默认收起，不再长期占宽
适合：想要现代感 / 自定义布局 打开 →
5 紧凑对比表 高密度
字号更小、间距更紧，行 = 轮次、列 = 模型，左侧问题列固定。目标是一屏看 8 个模型 × 多轮。
左侧问题列吸左，横向滚动时始终知道这行问的是什么
单元格默认截断 + 淡出，点一下展开全文
状态用颜色底 + 状态点表达，扫一眼就知道结果
工具栏可切「紧凑 / 舒适」两档密度
适合：模型多、快速扫差异 打开 →
5 个方案共用的改进点

◐建立色彩与层级体系

现在是「靠边框区分一切」。改成三级表面（主区 / 卡片 / 浮层）+ 三级文字， 并且给每个模型分配一个固定颜色，卡片、标签、列头、状态点统一使用，扫视成本大幅下降。

◱状态可视化

等待中 / 生成中 / 完成 / 失败 / 已取消，统一为「颜色点 + 文案 + 耗时」， 生成中带脉冲动画、失败用红色描边，不再依赖纯文字。

⇣拆分两个语义

「参与对比」（是否提问）与「显示结果」（是否展示）目前是两条长得很像的勾选栏，容易混。 每个方案里都用不同控件（开关 / 眼睛图标 / 收起列）把它们明确区分开。

⌨输入区升级

输入框给足高度、聚焦时描边高亮，附件缩略图带删除角标， 发送 / 停止位置固定，右侧显示「本轮几个模型参与」这类即时反馈。

☰历史会话重做

加搜索框、当前会话高亮、轮次徽标；删除仍是两段式但视觉更克制。 条目之间用留白而非分割线，列表不再显得拥挤。

◫空状态与错误态

错误给出「错误码 + 处理建议 + 重试按钮」；不支持图片的提示降级为浅色提示条； 空会话给出可操作的上手指引，而不是一段说明文字。

怎么选

只想让现在这版变好看

选方案 1。结构改动最小，主要是把两条勾选栏挪走 + 换配色与卡片样式，落地成本最低。

最在意「对比」这件事

选方案 2。列头吸顶 + 等宽对齐，是 5 个里唯一能真正做到「横向逐条对照」的布局。

模型多、回答长

选方案 3 或 5。3 适合细读，5 适合快速扫描，两者可以共存（视图切换）。

想要眼前一亮

选方案 4。代价是交互最多（浮动层、抽屉），实现与调试成本也最高。
