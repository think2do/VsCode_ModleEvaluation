# 多模型对比对话 —— 安装与上手

一个 VS Code 插件：把同一个问题**同时**发给多个 AI 模型，然后把它们的回答一个个读过去。

**当前版本 0.9.0** ｜ 覆盖 Windows / macOS / Linux

---

## 一、装之前先确认

| 检查项 | 要求 | 怎么查 |
|--------|------|--------|
| VS Code 版本 | **1.137.0 或更高** | 菜单 `Code` → `关于 Visual Studio Code` |
| 系统 | 三平台都行 | 插件本身与系统无关 |

> 版本低于 1.137.0 的话：菜单 `Code` → `检查更新`，升级并重启后再装。
> 这个插件用的是 VS Code 较新的「语言模型」接口，老版本没有。

## 二、安装（1 分钟）

拿到 **`multi-model-compare-0.9.0.vsix`** 后，任选一种：

**方式 1（最简单）**：直接**双击**这个 `.vsix` 文件，会弹出 VS Code 并询问是否安装，点「安装」。

**方式 2**：在 VS Code 里按 `Cmd+Shift+P`（Windows 按 `Ctrl+Shift+P`），
输入 `从 VSIX 安装`（Install from VSIX…），选中那个文件。

**方式 3**：命令行执行

```bash
code --install-extension multi-model-compare-0.9.0.vsix
```

装完后**重启 VS Code**（完全退出再打开，不是只关窗口）。

## 三、打开插件

`Cmd+Shift+P` → 输入 `多模型对比` → 选 **`多模型对比: 打开对比对话面板`**。

## 四、⚠️ 第一次用要配一下模型（重点）

**这个插件自己不带任何 AI 账号和密钥**，它只是借用**你自己 VS Code 里已经配好的模型**。

所以装完打开如果发现「模型列表是空的」或「列表里没有你想用的模型」，是正常的 ——
按下面的情况处理。

### 情况 A：你有 GitHub Copilot 订阅

先确认 VS Code 已登录 GitHub 且 Copilot 可用（右下角状态栏能看到 Copilot 图标）。

**然后建议改一个设置**（只做一次）：

打开设置（`Cmd+,`）→ 搜 `multiModelCompare.onlyPreferredVendors` → **取消勾选**。

> **为什么要改这个？**
> 插件默认只显示「你自己添加的模型」（就是你手动配了 API 地址的那种，见情况 B），
> 目的是让列表干净、不混进一大堆自带模型。
> 如果你只用 Copilot、没添加过自定义模型，面板顶上会出现一条提示：
> 「设置 multiModelCompare.preferredVendors 没有匹配到任何模型，本次临时显示全部可用模型」。
> **模型照样能用**，但那条提示每次打开都在。把这个开关关掉，提示就消失了。

改完回到面板，最上面那条就会列出全部模型（含 Copilot 的），用卡片右边的开关选你想对比的即可。

### 情况 B：你有自己的 API（OpenAI / DeepSeek / 通义 / 中转服务等）

需要先在 VS Code 里把你的服务商配上（**这一步在插件外面做**）：

1. `Cmd+Shift+P` → 输入 `管理语言模型`（Manage Language Models）
2. 添加你的服务商，填入 **API 地址** 和 **API Key**
3. 保存后回到插件面板，最上面那条里就会出现你配的模型

> 这类自己添加的模型是**默认就会显示**的，不用改任何设置。

### 三个可能有用的设置

在设置里搜 `multiModelCompare` 就能看到：

| 设置 | 默认 | 作用 |
|------|------|------|
| `preferredVendors` | `["customendpoint"]` | 「优先显示哪些来源的模型」。默认值 `customendpoint` 就是**你自己添加的**那类模型。一般不用改 |
| `onlyPreferredVendors` | 开 | 是否**只**显示上面那些。关掉 → 列出 VS Code 里**全部**可用模型（含 Copilot 自带的） |
| `maxSelectedModels` | `8` | 一次最多默认勾选几个模型。并发一次打到太多模型既费额度又容易触发限流；`0` = 不限制 |

改完**立即生效**，不用重开面板。

> 上面那条「没有匹配到任何模型」的提示，是因为 `preferredVendors` 里的
> `customendpoint` 在你机器上一个都没找到。**最简单的处理就是把
> `onlyPreferredVendors` 关掉** —— 这样它就不再做来源过滤，提示自然消失。

## 五、怎么用

1. 最上面那条里，用每张卡片**右边的开关**选要提问的模型（默认全开，最多 8 个）
2. 底部输入问题，**回车发送**（`Shift+回车` 换行）
3. 每个模型各答各的，**同时流式输出**，谁快谁先出字
4. 想追问就直接接着问 —— 每个模型各自记住自己的上下文，互不干扰

### 最上面那条：每张卡片能干三件事

界面最上面那条是悬浮着的，一张卡片上有**三个互不干扰**的控件：

| 点哪里 | 管什么 | 效果 |
|--------|--------|------|
| **最左边的复选框** | **怎么看** | 勾上 → 这个模型加入**并排对比**，勾几个下面就并排几个 |
| **卡片上的模型名** | **看谁** | 点一下 → 整个对话切到只看它（并排会退出） |
| **右边的开关** | **问不问它** | 关掉 → 不再向它提问（但已有的回答仍然看得到） |

### 几个好用的功能

| 想干什么 | 怎么做 |
|----------|--------|
| 把几个模型的答案**并排对照** | 勾上它们卡片**最左边的复选框**（勾几个并排几个） |
| **只看其中一个**模型的答案 | 点它的**模型名**（并排会退出）；或直接点回答标题栏上的模型名 |
| **不想再问**某个模型 | 关掉它卡片**右边的开关**（已答的内容仍然看得到） |
| **复制**某条回答 | 点回答标题栏的「复制」（复制的是 Markdown 原文，粘到别处格式还在） |
| **重新生成**某条回答 | 最新一轮答完后，点该条标题栏的「重新生成」 |
| **改刚发出去的问题** | 见下面单独一节 |
| **让模型看图** | 直接 `Cmd+V` 粘贴图片，或把图片拖进输入框（最多 4 张，单张 ≤ 20MB） |
| **中断生成** | 点「停止」（已生成的部分会保留） |
| **放大图片** | 点缩略图；再点一下或按 `Esc` 关闭 |
| **打开回答里的链接** | 直接点，会用系统浏览器打开 |
| **找回以前的对话** | 右侧「历史会话」列表点一下就恢复 |
| **删除某次对话** | 点它右边的 `✕`，再点一次变成的「确认」（要点两下，防止手滑） |

> 提问总是带「**你的提问**」标签和主题色底纹，模型回答前面有「**模型回答**」小标题 ——
> 一眼能分清谁说的。

### 改刚发出去的问题（只限最新一轮）

最新一轮提问的右上角有个「编辑」按钮，点开后可以直接改文字：

| 按钮 | 行为 |
|------|------|
| **仅保存** | 只改文字，已有的回答不动（适合修正错别字） |
| **保存并重新生成** | 用新问题**重新问本轮原有的那几个模型**（`Cmd` / `Ctrl` + 回车也行） |
| **取消** 或 `Esc` | 放弃修改 |

> 只有**最新一轮**能改 —— 改历史轮次会让后面的对话上下文自相矛盾。
> 带图片的轮次只改文字，图片原样保留。

### 把回答交给 Copilot 继续聊

每条回答的标题栏上还有两个按钮：

| 按钮 | 作用 |
|------|------|
| **导入单条** | 把这一条回答 + 对应提问，写成一个 Markdown 文件 |
| **导入本组** | 把**这个模型在整个会话里**的全部对话写成文件 |

点了之后插件会：把文件写进你当前打开的工程目录下的 `.multi-model-context/`，
自动打开它，并把**文件引用**复制到剪贴板。你切到 Copilot Chat，**粘贴**一下（形如 `#xxx.md`），
Copilot 就能读到这段对话接着聊。

> 没打开任何工程文件夹时，文件会写到别的地方（插件自己的数据目录），功能一样。
> 这个目录是纯本地的，随时可以删。

### 把某条回答设为「共享上下文」

点回答标题栏的「设为上下文」——之后**所有模型**提问时都会带上这条回答作为参考，
适合"让所有模型都基于 A 的回答继续讨论"。

设好之后顶部会话标题旁边会出现一个 `上下文：xxx · 第 N 轮 ×` 的小标签，点它就能取消。

## 六、关于隐私

- **对话和图片只存在你自己的电脑上**（VS Code 的本地数据目录里），不会上传到任何第三方
- 插件里**没有**任何 API Key，也不会读取你的密钥
- 提问内容只会发送到**你自己配置的那些模型服务**，跟用官方客户端是一样的

## 七、出问题了？

| 现象 | 怎么办 |
|------|--------|
| 命令面板搜不到「多模型对比」 | 确认已**完全退出并重启** VS Code；或去扩展面板搜「多模型对比对话」看是否被禁用 |
| 模型列表是空的 / 提示「没有找到可用模型」 | 见上面第四步 —— 还没配置模型，或 Copilot 未登录 / 未授权 |
| 列表里只有几个模型，找不到 Copilot 的 | 把设置里的 `multiModelCompare.onlyPreferredVendors` **关掉**（见情况 A） |
| 顶上总提示「preferredVendors 没有匹配到任何模型」 | 同上，关掉 `onlyPreferredVendors` 即可 |
| 列表里没有你配的自定义端点 | 检查 VS Code 里的 `chatLanguageModels.json` 是否写对（见下），然后重开面板 |
| 提示 `[NoPermissions]` | 首次使用某个模型时 VS Code 会请求授权，按弹窗允许即可 |
| 某个模型一直失败 | 可能该模型不支持图片；插件会自动去掉图片重试并标注「本次已仅发送文本」 |
| 一打开就勾选了很多模型 | 由 `multiModelCompare.maxSelectedModels` 控制（默认 8），设为 `0` 不限制 |
| 安装时提示版本不兼容 | 你的 VS Code 低于 1.137.0，先升级 |

自定义端点的配置文件位置：

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/Code/User/chatLanguageModels.json` |
| Windows | `%APPDATA%\Code\User\chatLanguageModels.json` |
| Linux | `~/.config/Code/User/chatLanguageModels.json` |

实在不行，可以去扩展宿主日志里找线索：

```
macOS:   ~/Library/Application Support/Code/logs/<最新时间戳>/window<N>/exthost/exthost.log
Windows: %APPDATA%\Code\logs\<最新时间戳>\window<N>\exthost\exthost.log
Linux:   ~/.config/Code/logs/<最新时间戳>/window<N>/exthost/exthost.log
```

搜 `multi-model-compare` 就能看到这个插件的运行记录。
