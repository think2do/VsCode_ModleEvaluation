# 多模型对比对话 —— 安装与上手

一个 VS Code 插件：把同一个问题**同时**发给多个 AI 模型，然后把它们的回答一个个读过去。

---

## 一、装之前先确认

| 检查项 | 要求 | 怎么查 |
|--------|------|--------|
| VS Code 版本 | **1.137.0 或更高** | 菜单 `Code` → `关于 Visual Studio Code` |
| 系统 | Windows / macOS / Linux 都行 | 插件本身与系统无关 |

> 如果版本低于 1.137.0：菜单 `Code` → `检查更新`，升级后重启再装。
> 这个插件用的是 VS Code 较新的「语言模型」接口，老版本没有。

## 二、安装（1 分钟）

拿到 `multi-model-compare-0.2.0.vsix` 文件后，任选一种：

**方式 1（最简单）**：直接**双击**这个 `.vsix` 文件，会弹出 VS Code 并询问是否安装，点「安装」。

**方式 2**：在 VS Code 里按 `Cmd+Shift+P`（Windows 按 `Ctrl+Shift+P`），
输入 `从 VSIX 安装`（Install from VSIX…），选中那个文件。

**方式 3**：命令行执行 `code --install-extension multi-model-compare-0.2.0.vsix`。

装完后**重启 VS Code**（完全退出再打开，不是只关窗口）。

## 三、打开插件

`Cmd+Shift+P` → 输入 `多模型对比` → 选 **`多模型对比: 打开对比对话面板`**。

## 四、⚠️ 第一次用要配一下模型（重点）

**这个插件自己不带任何 AI 账号和密钥**，它只是借用**你自己 VS Code 里已经配好的模型**。
所以打开后如果最上面那条显示「未发现可用模型」，或者提示找不到模型，是正常的 —— 需要你从下面选一种：

### 情况 A：你有 GitHub Copilot 订阅

最简单。确认 VS Code 已登录 GitHub 且 Copilot 可用（右下角状态栏能看到 Copilot 图标），
然后回到插件面板，最上面那条就会列出 Copilot 提供的模型，用卡片右边的开关选你想对比的即可。

### 情况 B：你有自己的 API（OpenAI / DeepSeek / 通义 / 中转服务等）

需要先在 VS Code 里把你的服务商配上：

1. `Cmd+Shift+P` → 输入 `管理语言模型`（Manage Language Models）
2. 添加你的服务商，填入 **API 地址** 和 **API Key**
3. 保存后回到插件面板，最上面那条里就会出现你配的模型

> 插件会把 VS Code 里可用的模型全部列出来（不区分来源）。如果模型太多，
> 可以在设置里搜 `multiModelCompare.maxSelectedModels` 限制默认勾选的数量。

## 五、怎么用

1. 最上面那条里，用每张卡片**右边的开关**选要提问的模型（默认全开）
2. 底部输入问题，**回车发送**（`Shift+回车` 换行）
3. 每个模型会各答各的，**同时流式输出**，谁快谁先出字
4. 想追问就直接接着问 —— 每个模型各自记住自己的上下文，互不干扰

界面最上面那条是悬浮着的，每张卡片可以干**三件互不干扰的事**：

- **点最左边的复选框** → 这个模型加入**并排对比**：勾几个，下面就横向排开几个，方便逐条比。
- **点卡片上的模型名** → 下面整个对话就切到这个模型，只看它的回答（并排会退出）。
- **点卡片右边的开关** → 这个模型**参不参与提问**。

几个好用的功能：

| 想干什么 | 怎么做 |
|----------|--------|
| 把几个模型的答案并排对照 | 勾上它们卡片最左边的复选框 |
| 只看其中一个模型的答案 | 把左边复选框都取消，再点它的名字（或直接点回答上的模型名） |
| 不想再问某个模型 | 把它卡片**右边的开关**关掉（已答的内容仍然看得到） |
| 复制某条回答 | 点回答标题栏的「复制」（复制的是 Markdown 原文） |
| 让模型看图 | 直接 `Cmd+V` 粘贴图片，或把图片拖进输入框 |
| 中断生成 | 点「停止」 |
| 找回以前的对话 | 右侧「历史会话」列表点一下就恢复 |

## 六、关于隐私

- **对话和图片只存在你自己的电脑上**（VS Code 的本地数据目录里），不会上传到任何第三方
- 插件里**没有**任何 API Key，也不会读取你的密钥
- 提问内容只会发送到**你自己配置的那些模型服务**，跟用官方客户端是一样的

## 七、出问题了？

| 现象 | 怎么办 |
|------|--------|
| 命令面板搜不到「多模型对比」 | 确认已**完全退出并重启** VS Code；或去扩展面板搜「多模型对比对话」看是否被禁用 |
| 提示「未找到可用模型」 | 见上面第四步 —— 你还没配置模型，或 Copilot 未登录 |
| 提示 `[NoPermissions]` | 首次使用某个模型时 VS Code 会请求授权，按弹窗允许即可 |
| 某个模型一直失败 | 该模型可能不支持图片输入；插件会自动去掉图片重试并标注 |
| 安装时提示版本不兼容 | 你的 VS Code 低于 1.137.0，先升级 |

实在不行，可以在扩展宿主日志里找线索：

```
~/Library/Application Support/Code/logs/<最新时间戳>/window<N>/exthost/exthost.log
```

（Windows 在 `%APPDATA%\Code\logs\` 下）
搜 `multi-model-compare` 就能看到这个插件的运行记录。
